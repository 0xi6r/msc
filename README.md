# c-reimplem

A simple repo of reimplementations of common tools, protocols, and anything around the software I use, written in C.

## Why?

To learn how things work under the hood. No better way than building them yourself.

## What's inside

- [ ] Basic tools (`ls`, `cat`, `grep`-like)
- [ ] Network protocols (HTTP, DNS, TCP)
- [ ] Utilities I use daily
- [ ] Text editor
- [ ] games
- [ ] ... more as I go
